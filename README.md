# Atividade 22: Semáforo Simples com Arduino 🚦

Este projeto foi desenvolvido como parte das atividades práticas do curso técnico em **Desenvolvimento de Sistemas do SENAI**. O objetivo é aplicar conhecimentos de lógica de programação e eletrônica básica para acender e apagar um LED utilizando a plataforma Arduino.

## 📝 Descrição
A atividade consiste na programação de um ciclo de iluminação para três LEDs (verde, amarelo e vermelho), respeitando tempos de espera específicos para simular um sinal de trânsito funcional. O projeto foi montado e testado através do simulador **Tinkercad**.

## 🛠️ Componentes
* **1** Arduino Uno R3
* **1** Protoboard
* **3** LEDs (Verde, Amarelo e Vermelho)
* **3** Resistores

## 🔌 Conexões (Pinagem)
| Componente | Pino Digital |
| :--- | :---: |
| LED Vermelho | 12 |
| LED Amarelo | 11 |
| LED Verde | 10 |
| Ground | GND |

## 💻 Como funciona
1.  **LED Verde** liga por um segundo.
2.  **LED Amarelo** liga por meio segundo.
3.  **LED Vermelho** liga por um segundo.
4.  O ciclo se repete indefinidamente.
